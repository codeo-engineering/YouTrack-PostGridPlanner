Getting Started

  1. Attach the app to your project: in YouTrack, open Administration → Apps → Post Grid Planner → Projects and click Manage projects.
  2. As a project admin, open Projects → your project → Settings → Post Grid Planner. The page lists the fields the planner uses and marks each one as Ready or Will be added.
  3. Optionally, enter product or brand names, separated by commas, to get one Instagram feed per product.
  4. Click Set up, review the changes and click Apply. The app adds Publish Date, the "Instagram Post" value in Type and, if selected, Ad Start Date, Ad End Date and a Product field.
  5. Open the Post Grid Planner tab in the project and click + New post. Enter a title and date and add an image. The post appears in the calendar and in the grid.
  6. To choose a carousel cover, attach the image in a comment and write cover in the same comment, or use an image whose file name contains "cover".

Users who aren't project admins can use the planner as soon as the setup is done. Creating new custom fields may need a YouTrack administrator.
